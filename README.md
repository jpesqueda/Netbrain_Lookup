# Netbrain Lookup

NetBrain endpoint lookup by IPv4 or MAC address. Standalone release 1.0.0, migrated from Netops-Tools 2.6.4 RC4.

Install locally with `python -m pip install -e .`. Run `Netbrain_Lookup` for the interactive terminal interface, or `Netbrain_Lookup --help` for CLI options.

Use the integrated terminal in VS Code or Windows Terminal. All examples use synthetic data. Reports may contain sensitive network data.

See README_ES.md and PROJECT_CONTEXT.md for usage and limitations. Publication requires CI and a live read-only validation.
